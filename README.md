# Не проси показать выход

Короткая психологическая игра-диалог о заброшенной деревне, умной девочке-мутанте и мальчике, которому нельзя вслух просить о спасении.

## Играть

[Запустить постоянную веб-версию](https://kiraobezjanka-sudo.github.io/dont-ask-for-the-way-out/)

## Цель

Заслужите доверие девочки, соберите два обязательных ориентира и вычислите безопасную дорогу. Если прямо попросить показать выход или вывести вас из деревни, программа девочки заставит её напасть.

## Управление

- Мышь или `1–3` — выбрать реплику.
- `Esc` / `P` — пауза.
- `Enter` — начать или продолжить.
- `R` — новая попытка после концовки.

## Локальный запуск

```powershell
npm run serve
```

Откройте `http://localhost:4173`.

## Проверка и сборка

```powershell
npm test
npm run lint
npm run build
```

Игра не использует внешние библиотеки, серверную часть или сетевые запросы.
