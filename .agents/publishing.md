# Git и публикация

- Рабочая ветка: `codex/npc-village-dialogue`; целевая ветка будущего PR — `main`.
- До личной проверки пользователем не создавать коммиты, удалённый репозиторий, PR или публикацию.
- Публикация требует отдельного явного одобрения после локальной проверки.
- Статический каталог — `dist/`; ветка Pages — `gh-pages`, в её корне обязателен `.nojekyll`.
- Временное превью PR имеет путь `/pr-preview/pr-<номер>/`; при закрытии удаляется только его собственный каталог.
- Постоянные и временные ссылки добавлять только после фактической проверки.
