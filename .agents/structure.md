# Технологии и структура

- Чистые HTML, CSS и JavaScript-модули без runtime-зависимостей.
- `src/game-data.js` хранит диалог, условия и эффекты.
- `src/game-model.js` — единственный источник истины для состояния игры и сериализуемого снимка.
- `src/app.js` связывает модель с DOM, вводом и необязательным Web Audio.
- `tests/` проверяет правила без браузера.
- `scripts/build.mjs` собирает статическую версию в `dist/`.
