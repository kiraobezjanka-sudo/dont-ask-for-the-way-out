# Проверка

Команды:

- `npm test` — тесты модели и всех ссылок диалога.
- `npm run lint` — синтаксическая проверка JavaScript.
- `npm run build` — чистая статическая сборка в `dist/`.
- `npm run serve` — локальный сервер на `http://localhost:4173`.

CI использует Node.js 24, `actions/checkout@v6` и `actions/setup-node@v6`.

Перед передачей проверить в браузере: старт, основную победную ветку, прямую смертельную просьбу, альтернативный финал, паузу/продолжение, перезапуск, клавиши `1–3`, мышь, ширины 1440 и 390 пикселей, отсутствие ошибок консоли.
